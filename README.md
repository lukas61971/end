# Endus Mroku

Mod do Minecraft Java 1.21.11 (Fabric). Projekt zaczyna się od bloku **Ciemne nylium**; kolejnym etapem będzie biom Endu i jego skaliste, pofalowane wyspy.

## Budowanie

Wymagane: Java 21 oraz Gradle. W katalogu projektu uruchom:

```sh
gradle build
```

Gotowy mod znajdziesz w `build/libs/`.

> To początkowy szkielet projektu. Wersje zależności i kompilację trzeba potwierdzić lokalnym buildem.
